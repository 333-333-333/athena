DR-001 CLI --db sqlite routing

RCA: CLI ignored --db because run() split argv as [command,...args] before option parsing, so a leading --db became the command and no sqlite path reached composition. Default CLI composition also fell back to dev sqlite only when its own factory was used.

Fix: Parse and strip --db before dispatch, pass sqlitePath into createComposition for every command, and default the CLI composition to sqlite with ATHENA_SQLITE_PATH or .athena/athena.sqlite in development. Also fixed init output to use the returned project instead of a missing get().
